# Portfolio content checklist

Goal: help an organizer understand Abhishek’s expertise, watch a talk and make contact in about a minute.

## Included

- [x] Full name, OpenCV maintainer role, engineering focus and Bengaluru location.
- [x] Direct actions to watch recordings and send a speaking invitation.
- [x] Four OpenCV recordings with verified official titles, thumbnails, publication months and descriptions.
- [x] Three proposed talk outlines with audience, experience level, duration and takeaways.
- [x] Selected upstream OpenCV case studies with pull-request sources and contribution credit.
- [x] Published writing with co-author credit and publisher links.
- [x] Short organizer bio with a text download.
- [x] Professional email, GitHub and LinkedIn links.
- [x] Travel and accommodation requirement outside Bengaluru.
- [x] Personal-capacity speaking statement.
- [x] Responsive layout, keyboard navigation, reduced-motion support, local fonts, canonical URLs, sitemap and RSS.
- [x] GitHub Pages deployment workflow for the requested address.

## Useful additions when available

- [ ] An approved high-resolution headshot for organizer downloads.
- [ ] Slide links and timestamps for Abhishek’s portions of shared recordings.
- [ ] A public reproducible demo repository for the inference talk.
- [ ] Audience feedback or organizer testimonials, with permission.
- [ ] Confirmed upcoming appearances after acceptance.

These additions are optional; missing items are not presented as placeholders on the website. Proposed topics are not represented as previously delivered conference talks.
